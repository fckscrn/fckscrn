Help

Everything on one page. Organizer things first, technical things at the end.

Quick start

  1. Create an event at fckscrn.com/nova-akce. Pick one room or several. You get a secret admin link; save it. It's the only way into the event, there's no sign-up.
  2. Add the programme. Got it in Excel or Google Sheets? Copy the table and click Paste programme from Excel. Otherwise add talks with + Talk.
  3. Send speakers their links (Speaker link button). Each uploads their own slides. Set a deadline and Remind speakers takes care of the rest.
  4. On the day open the room link in Chrome or Edge on the computer at the projector and start talks with one button.

Programme and rooms

  • Programme from Excel: select the table in Excel or Google Sheets, copy it (Cmd/Ctrl + C) and paste it into Paste programme from Excel. We recognise the columns (time, title, speaker, room, length), even without a header row, and show a preview first. Breaks and lunches are recognised by their name; times can be ranges like “9:15–9:45”.
  • By hand: + Talk, + Break or + Panel next to the room. The start time follows the previous block.
  • Edit or delete any item right in the programme.
  • Switch a one-room event to several rooms below the programme. An import creates the rooms from the table by itself.
  • Running late: the room control and the event admin show “You're 12 min behind”. Move the rest shifts everything that follows in that room. The room, door sign and event page pick up the new times automatically.

Speakers

  • Each speaker has a personal link; Speaker link copies it.
  • Deadline and reminders: set the Upload deadline. Speakers see it on their link and get a clear warning once it has passed. Remind speakers prepares a ready-to-send text with the link for everyone who hasn't uploaded; paste it into e-mail, WhatsApp or Slack.
  • Formats: PowerPoint (.pptx), Keynote (.key), PDF, OpenOffice (.odp), a Google Slides link, up to 2 GB. Slides can be replaced any time; a new version comes back to you for review.
  • Every upload is checked: aspect ratio (16:9), videos, notes. The speaker sees right away how it will look.
  • Speaker notes come from PowerPoint. Keynote and PDF don't carry them, but the speaker can type them next to each slide in the preview (saved automatically).
  • You can upload on a speaker's behalf (Upload for speaker), e.g. for a partner who e-mailed the file.
  • PowerPoint videos play right in the presentation, in their place on the slide, even offline. They start on their own or with the next click, as set in PowerPoint. The speaker monitor shows when the next click plays a video.
  • A YouTube or Vimeo video only plays if the room has internet, and an ad may run before it. A video the presentation only links to (a file on the speaker's computer) or an old format (WMV, AVI) won't play. You and the speaker see an Upload video button next to it: upload an MP4 and it plays offline.
  • Video sound goes to the projector's audio output (HDMI) automatically, otherwise to the computer's default sound. Pick another output (e.g. a USB mixer) in the room control below the screens. In the browser click Show audio outputs first: Chrome only shows speaker and HDMI names after you allow the microphone (nothing is recorded).

In the room

  1. In the admin, click Connect projection next to the room and open the link in Chrome or Edge on the computer connected to the projector.
  2. Click Allow screens so the browser can see the projector. If the browser blocks the window, allow pop-ups for FckScrn.
  3. On the right, set which screen is the Projection and which the Speaker monitor. The player remembers it. Just a laptop and a projector? The player sets the laptop to Control + speaker monitor: during a talk it shows the notes, time and slides with the buttons below. Programme brings back the full controls.
  4. Click Start projection, then press any key or the clicker once on the projector. It goes fullscreen and opens the speaker monitor. Browsers require that one key press. Then it stays until you close the window; a short Esc won't drop it (in Chrome only holding Esc leaves fullscreen). If it ever does, any key brings it back.

  • Keep the control tab open, it drives the projection. Everything is downloaded in advance, so if the internet drops, the show goes on.
  • Between talks the projection never shows the desktop: the partner loop runs, or black with the next talk.
  • Message to the speaker: “5 minutes left”, “Time's up” or your own text lights up big on the speaker monitor and the speaker's phone. The technician sends it from the room control, the organizer from the event admin (next to a running room). It clears itself after 5 minutes.
  • Phone as speaker monitor: the room control shows a QR code. The speaker scans it and mostly sees their notes, plus the time, the current, previous and next slide and messages from the technician, with big buttons to change slides (on a slide with a video the button plays it). On the last slide Questions on screen puts the audience questions up, and the speaker ticks them off. Handy without a stage monitor. Phone and room computer need internet.
  • Help button: on the speaker's phone. The room control flashes “The speaker needs help!” with a beep, and the organizer sees it in the admin. The technician clicks On my way and the speaker sees “The technician is on the way.”
  • The optional desktop app goes fullscreen by itself and can run the original in PowerPoint or Keynote. Paste the same room link into it.

Questions, polls and panels

  • Every talk and panel has its own QR code, small in the top left corner of the projection. The audience asks from their phones, name optional, no sign-up, and upvotes good questions.
  • Questions don't distract the speaker mid-talk. At the end the technician (or the speaker from the phone) puts them on the big screen with one click, and only then do they show on the speaker monitor too; during a panel they're always there. The speaker, moderator, technician or organizer ticks off answered ones: they leave the big screen, drop to the bottom on the monitor and a misclick can be undone; the organizer can hide one.
  • Questions on projection in the room control shows them across the screen with a large QR code.
  • Polls: the speaker (on their link) or the organizer (in the Questions window) writes a question and options, one per line, and clicks Start poll. Leave the options empty and people answer with one word, shown as a word cloud. The audience votes via the same QR code. Poll on projection in the room control shows the results live on the screen.
  • Add a panel with + Panel: topic, moderator, panelists one by one and optionally your own background (image or video).
  • Questions can be switched off per talk in the Questions window.

Partner loop

  • Drag photos (JPG, PNG, WebP, GIF, SVG) and videos (MP4, MOV) into the Partner loop in the admin, several at once if you like.
  • Set how long each photo shows and the order with the arrows. With several rooms, an item can play in one room only. Play loop shows how it will look on the projection.
  • Videos play in full, muted. The loop runs during breaks and between talks; it can be switched off in the room.

Event page and door signs

  • Under After the event in the admin, turn on the Public event page and send the link to attendees.
  • During the event it shows what's on in each room and what's next: what is really being projected, otherwise the schedule.
  • Door sign: below the page link there's a link for each room. Open it on a TV or tablet by the door and leave it: big “Now” and “Next”, refreshing by itself.
  • Your own door sign background: upload an image (SVG too), animation (GIF) or video (MP4, WebM, MOV) in the same place. It loops silently and “Now / Next” stays readable on top. It applies to all rooms' signs, which pick it up by themselves.
  • After the event it has the slides (PDF) of speakers who allowed it on their link. The page goes away with the event.

When something doesn't work

What happensWhat to do
The projection opened on the laptop, not the projectorIn the room control, set the projector's role to Projection. If the projector isn't listed, click Allow screens or unplug and replug it.
The projection window didn't openThe browser blocked it. Allow pop-ups for FckScrn in the address bar and click again.
The projection isn't fullscreenClick into the projection window or press a key or the clicker. The browser needs that one press.
A talk has no Start buttonThe speaker hasn't uploaded, or there's no PDF of the file yet. Check the admin. In a pinch, run the original in the desktop app.
A video in the slides doesn't playCheck the talk in the event admin: a linked video, YouTube without internet or an old format has an Upload video (MP4) button there. As a last resort run the original in PowerPoint from the desktop app.
No notes on the speaker monitorThe slides are PDF or Keynote. The speaker can type notes in the preview on their link; the room gets them on the next sync.
The internet went downNothing happens, the slides are downloaded. Questions, polls, the speaker's phone and messages wait until it's back.
The speaker's phone says “room offline”The room computer has no internet, or the room control isn't open. Check the control tab.
Lost the admin linkThere's no way in without it. Search your e-mail or browser history. Save it right after creating the event.

Activation and payment

Online, an event is free in trial mode: everything works, including a rehearsal in the room, with a "Zkušební režim" (trial) watermark over the projection. Click Aktivovat akci (activate), enter company details and an e-mail. The event is activated right away. The proforma invoice, due in 14 days, is right in the admin under Fakturace (PDF and a QR payment code); once the payment arrives the invoice appears there too, usually by the next day.

Data and security

  • Whoever has the admin link can manage the event. If it leaks, click Vytvořit nový odkaz (new link) in the admin; the old one stops working immediately.
  • A speaker link only allows uploading that speaker's file. A room link only allows playing that room's programme.
  • The event deletes itself with all files 14 days after its date. Before that you can download everything as one ZIP, or delete it right away.
  • Analytics: only on the public product pages (home, help) and only if you allow it in the “Cookies” bar. Event admin, speaker links, rooms and audience pages are never measured.

Claude and MCP

Dictate the programme to an AI assistant, by voice or text. FckScrn has an MCP server that Claude, ChatGPT and other MCP clients work with. Claude Code is the simplest (command below). In apps that add MCP as a connector (e.g. ChatGPT, Claude.ai), paste the connector address from the admin: https://fckscrn.com/mcp/<key>. No sign-in, the key is in the address. Copy the command from Control with AI in the admin:

claude mcp add --transport http fckscrn https://fckscrn.com/mcp --header "Authorization: Bearer <key from the admin link>"

The key is the last part of the admin link (/e/key). No separate API key is needed.

  • "Create an event Brno Meetup on 14 November, one room."
  • "Add a talk by Jana Dvořáková, Intro, at 18:00 for 10 minutes."
  • "Then Martin Kolář, AI in support." (the time follows automatically)
  • "Add a coffee break after him, 15 minutes."
  • "Who hasn't uploaded yet? Give me their links."

Tools: create_event, use_event, get_program, add_talk, add_break, update_talk, delete_talk, add_room, rename_room, speaker_links, event_status.

API

Everything the admin can do is available as a JSON REST API. Access is controlled by the secret tokens in the links: adminToken (/e/…, the whole event), speakerToken (/s/…, upload only), playerToken (/p/…, read the room's programme). The full endpoint list is in the Czech help; paths and fields are in English.

curl -X POST https://fckscrn.com/api/admin/<adminToken>/talks \
  -H "Content-Type: application/json" \
  -d '{"title":"Intro","speaker":"Jana","startsAt":"18:00","durationMin":10,"roomId":1}'

Self-hosting

FckScrn is open source (AGPL-3.0). On your own computer or server it's free, with no payments and no watermark. See INSTALL.md and DEPLOY.md in the GitHub repository, or open the repository in Claude Code or Codex and say "Install and run FckScrn according to INSTALL.md".
